### v6 M2 变更点

| 变更 | v5 | v6 M2 |
|------|-----|--------|
| 编译产物 | `App.gen.php` + `AppLayout_gen.php` | `*Component.php` (每个组件独立) |
| 组件注册 | `BaseRenderer.attachLayout()` | `Application.attachComponents()` |
| 布局来源 | `callLayoutSegment()` 函数 | `$component->getLayout()` 方法 |
| 初始化 | 手动 attach 所有布局 | 调用 `rootComponent->getBaseComponents()` |

## 4. Step 1：SFC 编译器（PHP CLI 预处理）

### 命令

```bash
php framework/sfc-compiler.php apps/calculator/App.vue
```

### 输入

| 输入 | 说明 |
|------|------|
| `apps/calculator/App.vue` | 主组件 SFC 文件 |
| `apps/calculator/components/*.vue` | 子组件 SFC 文件 |
| `project.yml` (components 节) | 组件标签 → 文件路径映射 |

### 输出 (v6 M2)

| 输出 | 说明 |
|------|------|
| `gen/AppComponent.php` | 根组件类，包含 `getLayout()`、`registerChildren()`、`getBaseComponents()` |
| `gen/DisplayPanelComponent.php` | 子组件类 |
| `gen/NumPadComponent.php` | 子组件类 |
| `gen/AboutDialogComponent.php` | 子组件类 |
| `gen/ComponentFactory.php` | 组件工厂，包含 `create()` 方法，使用 `any()` + switch-case (v6 M2 新增) |
| `gen/constants.php` | `WINDOW_WIDTH` / `WINDOW_HEIGHT` 常量 |

### SFC 编译器关键设计约束

- **运行在 AOT 之外**：标准 PHP CLI 脚本，不经过 AOT 编译
- **文件名**：输出文件只用 `[a-zA-Z0-9_]`，禁用点号（如 `AppComponent.php`）
- **子组件变量**：使用 `addChild(new Component(), $props)` 直接传入，避免中间变量类型问题
- **布局数据**：使用 `function getLayout(): array` 而非 `const LAYOUT = [...]`
- **正则分隔符**：避免 `#`（与 CSS 颜色冲突），优先用 `~`
- **工厂模式**：使用 `any()` 函数丢弃类型推断，生成 switch-case 工厂

## 5. Step 2：AOT 编译器（PHP → C++ → exe）

### 命令

```bash
swoole_compiler.exe apps/calculator/project.yml -f
```

### project.yml 配置 (v6 M2)

```yaml
name: calculator
version: 1.0.0
mode: bin
no-console: false
sources:
  # 应用代码
  - main.php
  - Application.php
  - ./gen                    # SFC 编译产物目录
  # 框架运行时
  - ../../framework/interfaces/ComponentInterface.php  # v6 M2 新增
  - ../../framework/BaseComponent.php
  - ../../framework/ReactiveComponent.php
  - ../../framework/ChangeQueue.php
  - ../../framework/BaseRenderer.php
  - ../../framework/rendering/RenderContext.php
  - ../../framework/rendering/GdiRenderContext.php
  # C++ 桥接层
  - ../../stub
  - ../../cpp

# 组件注册表（编译器读取，AOT 忽略）
components:
  display-panel: ./components/DisplayPanel.vue
  num-pad: ./components/NumPad.vue
  about-dialog: ./components/AboutDialog.vue
```

### sources 配置规则 (v6 M2 新增)

| 规则 | 说明 |
|------|------|
| **接口必须包含** | `ComponentInterface.php` 等接口文件必须显式列出 |
| **基类必须在实现前** | 先列接口，再列基类，最后列继承类 |
| **目录递归** | `./gen` 会自动包含所有 `.php` 文件 |

## 7. 常见构建错误速查

### 7.1 SFC 编译器错误

| 错误 | 根因 | 修复 |
|------|------|------|
| `Error: No <template> block found` | .vue 文件缺少 `<template>` 标签 | 确保三个块都存在 |
| `Unknown modifier '('` | 正则分隔符 `#` 与 CSS 颜色 `#` 冲突 | 改用 `~` 分隔符 |
| `Elements: 2 (rects + texts)` 而非 4 | `[a-z-]+` 不匹配 `:bind` | 改为 `[a-z:@-]+` |
| 按钮颜色全是默认灰色 | 颜色正则匹配失败 | 检查 hex 颜色正则分隔符 |

### 7.2 AOT 编译器错误

| 错误 | 根因 | 修复 |
|------|------|------|
| `'cl' 不是内部或外部命令` | MSVC 环境未初始化 | 先运行 `vcvarsall.bat x64` |
| `Class X implements a non-existent interface` | `sources` 缺少接口文件 | 添加 `ComponentInterface.php` 到 sources |
| `Cannot re-assign typed object` | 同一变量赋值不同类型 | 使用 `addChild(new Component(), $props)` 直接传入 |
| `All execution code must be within a function` | `require_once` 写在顶层 | 移除；AOT 通过 sources 自动链接 |
| `Expression must be a global, non-magic constant` | `__DIR__` 在属性默认值 | 移到构造函数 |
| `error C3927/C3484: "->"` | 文件名含点号生成无效 C++ 符号 | 改下划线 `_gen.php` |
| `Cannot redeclare class X` | `require_once` 在 AOT 中重复声明 | 移除 require |
| `Undefined variable $xxx` | 使用未定义变量 | 先赋初始值（如 `= null`） |
| LAYOUT 常量未注册 | `const` 不支持复杂数组 | 改用 `function getLayout()` |

## 8. AOT 兼容性规则（必读）

### 禁止使用的 PHP 特性

| 特性 | 说明 | 替代方案 |
|------|------|----------|
| `$$` 动态变量 | 编译器无法确定变量名 | 用数组 |
| `__get` / `__set` | 魔术方法在 C++ 中不调用 | 声明 public 属性 |
| 同一变量赋值不同类型 | AOT 类型不可变 | 用不同变量名或直接传入函数 |
| 反射 (`ReflectionClass` 等) | 运行时动态 | 编译期确定 |
| `eval()` / `include` 动态加载 | 运行时编译 | .vue → SFC 编译器预处理 |
| 字符串含 `\0` | 与 C++ 不兼容 | 不要用 null 字节 |

### 必须遵守的规则

1. **所有代码在函数内**：不允许顶层游离代码
2. **变量先定义后使用**：`isset($undef)` 在 AOT 中恒为 true
3. **类型不可变**：变量不能从 string 变为 object
4. **对象类型不可变**：不能 `$o = new A(); $o = new B();`
5. **文件名只用 `[a-zA-Z0-9_]`**：避免 C++ 符号名冲突
6. **全局 const 只用标量**：复杂数组用 function 返回
7. **类方法中遍历外部函数返回的数组**：必须用 `is_array()` 检查
8. **接口必须在 sources 中**：新增接口文件必须添加到 project.yml

### 数组遍历安全模式

```php
// ✅ 推荐：for + array_keys + 安全检查
$keys = array_keys($arr);
$count = count($keys);
for ($i = 0; $i < $count; $i++) {
    $item = $arr[$keys[$i]];
    if (!is_array($item)) continue;
    process($item['x'] ?? 0, $item['y'] ?? 0);
}

// ✅ condition 字段检查
$cond = $item['condition'] ?? null;
if ($cond !== null && !is_array($cond)) continue;
if ($cond !== null && !$this->component->evalCondition($cond)) continue;
```

### 子组件注册模式 (v6 M2 新增)

```php
// ❌ AOT 不兼容：同一变量赋值不同类型
$child = new DisplayPanelComponent(...);
$child = new NumPadComponent(...);  // 错误!

// ✅ AOT 兼容：直接传入
$this->addChild(new DisplayPanelComponent(...), [...]);
$this->addChild(new NumPadComponent(...), [...]);
```
